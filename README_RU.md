# Шашки Бот AUTO — Android Studio проект

## Что включено
- Приложение на Kotlin для Android.
- Встроенная доска 8×8 с начальной расстановкой русских шашек.
- Проверка части правил: обычные ходы, обязательное одиночное взятие, превращение в дамку, ходы дамки.
- Простой советчик, который предпочитает взятия и продвижение.
- AccessibilityService для двух нажатий по координатам после явного нажатия пользователем кнопки.

## Ограничения текущей версии
Это **не законченный автоигрок**. Встроенный движок пока не реализует все варианты многоходовых взятий и не является сильным minimax-движком. Внешняя игра Blitz Tournament автоматически не распознаётся: здесь пока нет MediaProjection, компьютерного зрения, определения границ доски и автоматического сопоставления клеток с координатами экрана. Поэтому приложение не должно само играть в сторонней игре на текущем этапе.

## Сборка APK
1. Установи Android Studio на компьютер.
2. Распакуй ZIP.
3. В Android Studio выбери **Open** и укажи папку `ShashkiBotAuto_Android`.
4. Дождись синхронизации Gradle.
5. Выбери **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
6. APK будет в `app/build/outputs/apk/debug/app-debug.apk`.

## Разрешение на нажатия
Кнопка в приложении открывает настройки специальных возможностей. Включай этот сервис только если понимаешь, что он позволяет приложению выполнять касания по экрану. Не включай его для недоверенных приложений. Проверь координаты на безопасном экране перед тестом.

## Требования
- Android Studio с Android Gradle Plugin 8.7.3.
- JDK 17.
- Android SDK Platform 35.
