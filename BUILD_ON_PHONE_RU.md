# Как собрать APK без компьютера

1. Скачай и распакуй архив на телефоне (например, в приложении «Файлы»).
2. Открой github.com в браузере и войди или создай аккаунт.
3. Создай новый пустой репозиторий.
4. Загрузи в него все файлы проекта из распакованной папки, включая скрытую папку `.github`.
5. Открой вкладку Actions в репозитории.
6. Выбери workflow «Build Android APK» и нажми Run workflow.
7. После успешной сборки открой завершённый запуск workflow, пролистай до Artifacts и скачай `ShashkiBotAuto-debug-apk`.
8. Распакуй скачанный артефакт и установи APK. Android может попросить разрешить установку из этого браузера/файлового приложения.

Важно:
- Это облачная сборка, не требует компьютера, но нужен аккаунт GitHub и интернет.
- APK будет debug-сборкой для тестирования.
- Текущий код — прототип: он не распознаёт автоматически стороннюю игру и не играет в ней сам.
- В архиве нет Gradle Wrapper, поэтому workflow использует установленный в runner Gradle. Если сборка завершится ошибкой, пришли скриншот ошибки — помогу исправить.
